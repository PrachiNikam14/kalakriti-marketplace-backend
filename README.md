# Kalakriti Marketplace Backend

Backend system for a handmade products marketplace.

## Tech Stack
- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL
- REST APIs

## Features
- User authentication
- Product management
- Cart system
- Order management
- Product reviews

## Architecture

Controller → Service → Repository → Database

## Tools
- IntelliJ IDEA
- Postman
- Git
